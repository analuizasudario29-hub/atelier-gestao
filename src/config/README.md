# src/config

Esta pasta está reservada para as **próximas etapas** do projeto (ainda vazia de propósito).

Aqui deverão entrar futuramente, por exemplo:

- `supabaseClient.js` — inicialização do cliente Supabase
- `googleAuth.js` — configuração do Google OAuth
- `payment.js` — configuração do gateway de pagamento

Nenhum desses arquivos foi criado nesta etapa, conforme solicitado.
As variáveis necessárias para essa configuração devem vir de variáveis
de ambiente (veja `.env.example` na raiz do projeto).
